# AGENTS.md

Guidance for coding agents working in this repository. For user-facing usage docs see
`README.md`; for the human contributor workflow see `CONTRIBUTING.md`.

## What this is

A Rust 2024 Cargo workspace that publishes the `inference-gateway-sdk` crate: a thin
client for the Inference Gateway HTTP API. Workspace members: `.` (the SDK),
`tools/gen-types` (OpenAPI code generator), and `examples/{list,chat,messages}`
(runnable example clients, `publish = false`).

Hand-written code lives in `src/lib.rs` (`InferenceGatewayClient` plus the
`InferenceGatewayAPI` trait) and `src/ext/`. HTTP behavior is tested with `mockito`
in `src/tests.rs`.

## Commands

- `task test` — `cargo test --all-targets --all-features`
- `task lint` — `cargo fmt --all -- --check` + markdownlint
- `task analyse` — `cargo clippy --all-targets --all-features -- -D warnings`
  (British spelling; `task analyze` does not exist)
- `task generate-types` — regenerate `src/generated/schemas.rs` from `openapi.yaml`
- `task oas-sync` — fetch the upstream OpenAPI spec (pin with `SCHEMAS_REF`) and
  regenerate types

Run one test with `cargo test <name-substring>`. Toolchain is pinned to Rust 1.95.0 in
`rust-toolchain.toml`; the dev environment is managed with flox (`flox activate`).

## Generated code boundary

- `src/generated/schemas.rs` is generated by `tools/gen-types` from `openapi.yaml`.
  Never edit it by hand: change the spec or `tools/gen-types/src/main.rs` and re-run
  `task generate-types`. CI fails if regeneration produces a diff.
- `openapi.yaml` is a copy of the upstream spec at `inference-gateway/schemas`; treat it
  as read-only. Fix divergences upstream and pull them in with `task oas-sync`. If a
  hand-patch here is unavoidable, add it to `apply_known_patches` in
  `tools/gen-types/src/main.rs` with a comment.
- The generator emits `Display`/`FromStr` for enums; don't reimplement them.

## Style & testing

Use `rustfmt` (LF endings, final newlines, 4-space indentation per `.editorconfig`) and
idiomatic Rust naming (`PascalCase` types, `snake_case` functions). Add tests for new
behavior, bug fixes, and serialization changes: `test_*` functions in `src/tests.rs`
with `#[tokio::test]` and `mockito::Server` for HTTP expectations. Run `task test`
before opening a PR and `task analyse` when touching shared client or generated-type
logic.

## Commits & releases

Conventional Commits (`feat`, `fix`, `refactor`, `docs`, `style`, `test`, `chore`,
`ci`, `perf`). Semantic-release rewrites `CHANGELOG.md` and the `version` in
`Cargo.toml` on merge to `main` — do not hand-edit either.

## Security & configuration

Never commit real credentials; `.env.example` is the template for local configuration.
`InferenceGatewayClient::new_default()` reads `INFERENCE_GATEWAY_URL` and falls back to
`http://localhost:8080/v1`.
